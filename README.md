# Student Score Predictor - AI & ML Project 🚀

## Overview
This is my final Machine Learning project for my internship at **Codomax Digital Solutions**. 
The project uses Simple Linear Regression to predict the percentage of marks a student is expected to score based on the number of hours they studied.

## Tech Stack Used
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib

## How It Works
1. Uses a dataset of 'Hours Studied' and 'Scores'.
2. Splits data into training (80%) and testing (20%) sets.
3. Trains a **Linear Regression** model using Scikit-Learn.
4. Predicts the score for new inputs (e.g., predicting score for 9.5 hours of study).
5. Visualizes the regression line using Matplotlib.

## Results
* The model successfully learned the linear relationship between study hours and exam scores.
* **Accuracy (R2 Score):** ~0.96 (96%)
